Simple Object Manager

This extension has been created to provide an easy way to manage simple objects via methods encapsulating recursive logics.

The extension allows you to define variable names that will be used to create and manipulate objects in your scripts.

For more information on the methods, please refer to the GitHub repository.

Variable Name Configuration

Define the names of the variables you want to create in the 'window' context.

Validation

Ensure that each variable name is unique and valid.

Even if no variables are defined, the extension will load automatically the Som class in the 'window' context.
You can then use the Som class methods directly.
